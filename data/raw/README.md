# Dados brutos
Os dados brutos originais não são publicados neste repositório para preservar a confi
Para reproduzir o projeto, use uma base anonimizada com as colunas descritas em `docs
## Regras de anonimização
Antes de adicionar qualquer arquivo a esta pasta, remova ou substitua:- Nome da empresa.- CNPJ.- Endereço.- Telefone.- E-mail.- Nome ou identificação de clientes.- Número de pedido, nota fiscal ou identificadores internos.- Informações que permitam reconhecer fornecedores ou funcionários
